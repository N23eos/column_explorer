# План: Column Explorer v1.3.0 — вид колонок + цвета папок

## Цель
1. Переключатель вида внутри каждой колонки: список ↔ значки (сетка плиток)
2. Правый клик по папке → назначить цвет (палитра + сброс)

## Дизайн

### Вид колонки
- Кнопка list/grid в заголовке каждой колонки
- Режим хранится per-folder в данных плагина (`columnViewModes: Record<path, "list"|"grid">`),
  переживает перезапуск
- Grid: CSS grid из плиток (иконка сверху, имя снизу), та же delegation-логика —
  меняется только CSS-класс списка и раскладка item
- Клавиатура в grid работает как в списке (линейный порядок)

### Цвета папок
- Контекстное меню папки → «Цвет папки» → 8 пресетов Obsidian
  (red/orange/yellow/green/cyan/blue/purple/pink) + «Стандартный»
- Пресеты через нативные CSS-переменные темы (`var(--color-red)` и т.д.) —
  корректно в светлой и тёмной теме
- Цветной кружок в пунктах меню (DocumentFragment в setTitle — публичный API)
- Хранение: `folderColors: Record<path, colorKey>` в данных плагина
- Применение: CSS-переменная на item → красится иконка папки (+имя чуть тонировано)
- Rename папки → ключи remap'ятся (включая вложенные), delete → ключ удаляется
- Чистая функция `remapPathKeys` в pure.ts + юнит-тесты (TDD)

## Порядок
1. Тесты `remapPathKeys` + `prunePathKeys` (RED) → GREEN в pure.ts
2. Данные: расширить settings/data, remap на rename/delete
3. Цвета: меню, применение в column.ts, CSS
4. Вид: кнопка в заголовке, grid CSS, persist
5. i18n en/ru, build+lint+tests, версия 1.3.0, коммит, пуш, тег

## 2. Оптимизация

- **Event delegation**: сейчас ~6 listener'ов на каждый файл. Станет: по одному
  click/dblclick/auxclick/contextmenu/dragstart/drop-набору на колонку,
  элемент определяется через `closest("[data-path]")`. На vault 5000+ файлов —
  кратно меньше памяти и быстрее рендер.
- **Точечный re-render**: события vault (create/delete/rename) перерисовывают
  только колонки, чей folder затронут, а не всё дерево. Debounce остаётся.
- Прогон: рендер колонки на 1000 элементов через DocumentFragment (уже есть) — сохраняем.

## 3. Новые фичи

1. **Breadcrumbs** — кликабельный путь под тулбаром (сегменты = переход к глубине)
2. **Resize колонок** — перетаскивание правой границы колонки, ширина сохраняется в настройках
3. **Type-ahead** — набор букв в колонке прыгает к совпадающему файлу (как в Finder)
4. **Markdown-превью** — в колонке превью рендерится начало заметки (MarkdownRenderer, ~1000 символов), toggle в настройках
5. **Exclude-паттерны** — настройка «скрывать файлы/папки по паттернам» (glob-подобные, через запятую)
6. **Home/End/PageUp/PageDown** в клавиатурной навигации
7. **Меню мультивыделения** — «Переместить в папку…» (модал с выбором), «Дублировать», «Удалить» (сейчас только удалить)
8. **Auto-reveal** — toggle «автоматически показывать активный файл» (следит за active-leaf-change)
9. **A11y** — role="listbox"/"option", aria-selected, видимый фокус
