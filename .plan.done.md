# План: фиксация панели (режим одной колонки)

## Цель
Кнопка-замок в тулбаре. Панель зафиксирована → рендерится одна колонка (текущая папка),
клик по папке заменяет содержимое этой же колонки, новые колонки не появляются.
Назад — хлебные крошки или ArrowLeft. Состояние переживает перезапуск.

## Ключевое наблюдение
`selection[]` (цепочка путей) — единственный источник правды для навигации.
Клики, клавиатура, крошки, reveal — всё уже работает через него.
Меняем ТОЛЬКО то, как `render()` отображает selection: одна колонка вместо цепочки.
Вся остальная логика (selectItem, onKeyDown, doRefresh, drag&drop) не трогается.

## Шаги

1. **settings.ts** — поле `panelLocked: boolean` в `ColumnExplorerSettings`, default `false`.
   В UI настроек не выводим (управление только кнопкой).
   → verify: `npm run build` без ошибок.

2. **i18n.ts** — строки `lockPanel` / `unlockPanel` (en + ru).
   → verify: build.

3. **view.ts**:
   - Тулбар: кнопка после «Свернуть к корню». Иконка `lock-open` (разблокировано) / `lock`
     (заблокировано), класс `is-active` на кнопке при фиксации. Клик: переключить
     `settings.panelLocked`, сохранить настройки, обновить иконку, `render()`.
   - `render()`: ветка для `panelLocked`:
     ```
     если заблокировано:
         folder = this.currentFolder()          // уже есть
         depth  = индекс folder в selection + 1 // 0 для корня
         renderColumn(this, columnsEl, folder, depth)  // одна колонка
         колонка превью не рендерится
     иначе: существующий код без изменений
     ```
     `depth` считаем тем же обходом, что в `currentFolder()` (последняя папка в цепочке).
     Класс `is-locked` на `columnsEl` для CSS.
   → verify: build + ручная проверка в Obsidian.

4. **styles.css** — при `.is-locked`: колонка растягивается на всю ширину панели,
   resize-handle скрыт.
   → verify: визуально.

5. **Проверка регрессий** — `npm test` (vitest) + `npm run lint` + `npm run build`.
   Новых pure-функций нет — новые unit-тесты не требуются (паттерн репо:
   тестируется только `pure.ts`).

## Почему ничего не сломается
- Обычный режим: путь в `render()` не изменён (else-ветка).
- Клавиатура/клики/крошки/reveal оперируют `selection`, семантика не меняется.
- `doRefresh` ищет колонку по `data-folder-path`; невидимая папка → querySelector null → skip (уже так).
- Снятие фиксации: `selection` цепочка сохранена → колонки Миллера восстанавливаются как были.
