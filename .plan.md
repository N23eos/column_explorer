# План: свой трекер недавних (до 50) + улучшение настроек

## Цель
Колонка «Недавние» показывает до 50 последних открытых файлов.
Obsidian хранит только 25 md — ведём свой список.

## Допущения (поправь, если не так)
- Свой список `recentFiles: string[]` в data.json, новые сверху, кап 50.
- Слушаем `file-open` в main.ts (плагин всегда жив, вью может быть
  закрыта); rename/delete — правим список там же.
- Первый запуск: список пуст → засеваем из getLastOpenFiles() (10 шт),
  дальше накапливается само. Приватный getRecentFiles больше не нужен.
- Слайдер 5–50, дефолт оставляю 10 (плагин публичный); тебе в Raincoat
  просто двинуть слайдер на 50.
