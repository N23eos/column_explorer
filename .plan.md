# План: число вместо ползунка + календарь + закладки

## Сложность (оценка)
- Число недавних: тривиально.
- Календарь: средняя — сетка месяца своя (~200 строк с CSS).
- Закладки: небольшая; API закладок у Obsidian приватный
  (internalPlugins) — оборачиваем try, при выключенном core-плагине
  «Закладки» пункт скрывается сам.

## Что делаем
1. Настройка «Число недавних файлов»: input-число 5–50 (не слайдер).
2. Пункт «Календарь» в первой колонке (вкл/выкл в настройках):
   колонка с сеткой месяца, ‹ › листают месяцы, в ячейке дня — число
   созданных заметок (бейдж), клик по дню → колонка с файлами,
   созданными в этот день (по ctime), клик по файлу открывает.
3. Пункт «Закладки» (вкл/выкл): колонка с файлами из core-плагина
   Bookmarks (группы разворачиваем плоско, только файлы).

## Допущения (поправь, если не так)
- «Создан в этот день» = f.stat.ctime (дата создания файла на диске).
- Календарь открывается на текущем месяце; выбранный день подсвечен.
- Порядок пунктов в корне: Недавние, Закладки, Календарь.
- Счётчик в ячейке — только число, без точек-миниатюр.
