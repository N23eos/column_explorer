# План: импорт файлов из ОС (drag&drop) + первая колонка шире

## Цель
1. Файл из Finder бросили в колонку → он копируется в vault в эту папку.
2. Первая (корневая) колонка по умолчанию шире остальных — ярлыки влезают.

## Допущения (поправь, если не так)
- Из ОС тащим только файлы, не папки (папки из Finder — отдельная сложная
  история через webkitGetAsEntry, пока вне скоупа).
- «Чуть шире» = +60px к дефолтной ширине (200 → 260). Ручкой всё ещё можно
  перетянуть, dblclick-сброс вернёт к 260, а не к 200.
- При совпадении имени не перезаписываем: «name 1.ext», «name 2.ext»…
