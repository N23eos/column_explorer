# План: фиксация числа колонок (скользящее окно) — итерация 3

## Цель (спецификация пользователя)
Замок фиксирует ЧИСЛО видимых колонок:
- клик по папке в последней колонке НЕ создаёт новую колонку — окно сдвигается
  вправо ([Vault][Проекты][Идеи] + клик Sub → [Проекты][Идеи][Sub]);
- клик по любой колонке левее последней снимает фиксацию;
- состояние переживает перезапуск.
Заменяет вариант «папка как временный корень» (lockedFolderPath, a79b005).

## Ключевая идея
selection[] и вся навигация не меняются. Меняется только окно рендера:
показываем последние N колонок цепочки. N берём в момент нажатия замка.

   - кнопка: lock → count = folderColumnCount(), unlock → null;

   - selectItem(): если locked и depth < folderColumnCount()−1 (клик левее
     последней колонки) → unlock;
   - remap/prune для lockedFolderPath удалены (count не привязан к пути).

## Поведение по краям
- ArrowLeft / крошки (навигация влево): окно скользит влево, замок остаётся.
- Цепочка короче N: показываются все колонки, замок остаётся.
- Замок в единственной колонке (корень): N=1 → навигация в одной колонке.
- Удаление/переименование папок: selection чинится существующей логикой,
  окно пересчитывается — сбрасывать нечего.
- Старые ключи panelLocked / lockedFolderPath в data.json игнорируются.
- Колонка превью (showPreview) в счёт N не входит.
