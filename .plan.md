# План: фиксация любой колонки как временного корня

## Цель
Кнопка-замок фиксирует ТЕКУЩУЮ папку (любой глубины) как временный корень:
колонки левее скрыты, правее — обычные Miller-колонки, навигация глубже
добавляет колонки вправо. Клик по крошке / ArrowLeft выше зафиксированной
папки снимает фиксацию. Состояние переживает перезапуск.

## Допущения (подтвердить)
- Старый режим «одна колонка» (panelLocked) ЗАМЕНЯЕТСЯ новым поведением —
  кнопка та же, boolean-флаг уходит.
- Фиксация в корне = обычный вид (без эффекта), это допустимо.

## Ключевая идея
Навигация не меняется вообще: selection[], selectItem, клавиатура, крошки —
всё как есть. Меняется только render(): пропускаем колонки с depth <
lockDepth. Сброс — инвариант в render(): если lockedFolderPath больше не
в цепочке selection → снять фиксацию.

## Вне скоупа
- Несколько одновременных фиксаций (массив) — не нужно при выбранной семантике.
- Пункт в контекстном меню колонки (можно добавить потом).

## Риски
- Забытый сброс при delete/rename locked-папки → лечится инвариантом в render()
  (папка не найдена в цепочке → unlock) + ремапом при rename.
- Старое сохранённое panelLocked:true в data.json просто игнорируется.
