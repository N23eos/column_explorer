## 2. Оптимизация

- **Event delegation**: сейчас ~6 listener'ов на каждый файл. Станет: по одному
  click/dblclick/auxclick/contextmenu/dragstart/drop-набору на колонку,
  элемент определяется через `closest("[data-path]")`. На vault 5000+ файлов —
  кратно меньше памяти и быстрее рендер.
- **Точечный re-render**: события vault (create/delete/rename) перерисовывают
  только колонки, чей folder затронут, а не всё дерево. Debounce остаётся.
- Прогон: рендер колонки на 1000 элементов через DocumentFragment (уже есть) — сохраняем.

## 3. Новые фичи

1. **Breadcrumbs** — кликабельный путь под тулбаром (сегменты = переход к глубине)
2. **Resize колонок** — перетаскивание правой границы колонки, ширина сохраняется в настройках
3. **Type-ahead** — набор букв в колонке прыгает к совпадающему файлу (как в Finder)
4. **Markdown-превью** — в колонке превью рендерится начало заметки (MarkdownRenderer, ~1000 символов), toggle в настройках
5. **Exclude-паттерны** — настройка «скрывать файлы/папки по паттернам» (glob-подобные, через запятую)
6. **Home/End/PageUp/PageDown** в клавиатурной навигации
7. **Меню мультивыделения** — «Переместить в папку…» (модал с выбором), «Дублировать», «Удалить» (сейчас только удалить)
8. **Auto-reveal** — toggle «автоматически показывать активный файл» (следит за active-leaf-change)
9. **A11y** — role="listbox"/"option", aria-selected, видимый фокус
