# План: пункт «Недавние» в первой колонке + настройка количества

## Цель
Вверху корневой колонки виртуальный пункт «Недавние» (иконка-часы).
Клик → вторая колонка со списком последних открытых файлов
(источник — `app.workspace.getLastOpenFiles()`). Клик по файлу — открывает
его. В настройках слайдер «сколько показывать», дефолт 10.

## Допущения (поправь, если не так)
- Сентинел-путь `::recents::` — двоеточие в именах файлов Obsidian
  запрещено, коллизий с реальными путями нет.
- В колонке «Недавние» нет: drop-приёма, переименования inline, пинов,
  сортировки. Тащить ИЗ неё и контекстное меню файла — работают
  (файлы реальные).
- Из «Недавних» вглубь не ходим: клик по файлу открывает его и (если
  включено превью) показывает колонку превью.
- Слайдер 5–30, шаг 1, дефолт 10.

## Риски
- getLastOpenFiles может вернуть удалённые пути — фильтруем через
  getAbstractFileByPath (шаг 1 как раз про это).
- Спец-ветки в click/render: не сломать обычную навигацию (регресс-тест
  руками: корень → папки → файл, замок, фильтр).
